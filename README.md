# Terminal Music Player

A simple command-line music player built using Node.js. The application runs completely in the terminal and allows the user to select and control local MP3 songs.

## Features

- Display available songs
- Select a song from the terminal
- Play music
- Pause music
- Resume music
- Increase volume
- Decrease volume
- Replay the current song
- Quit the application

## Technologies Used

- Node.js
- JavaScript
- Node.js `readline`
- Node.js `child_process`
- Node.js `fs`
- Node.js `path`
- macOS `afplay`
